## 原项目专项条目

- 列表结构诊断沿用 `validation/mp_source.py`，仅输出固定字段的类型、数量和固定原因码，不保存原始响应、任意字段名或上游错误字符串。默认不跟随重定向；验证桥只允许两篇固定样本在相同 HTTPS 主机下、经公开文章标识校验的一次跳转，其他端点／跨站／换文／再次跳转均停止。敏感 URL 和头部只经 stdin／私有 FIFO，不进入命令行、普通配置文件或日志，不自动换传输重试。
- `validation/sample_check.py` 仅串行核对两篇固定技术样本，复用 HTTP 归档和原页截图入口，不访问文章列表或启用订阅。显式 credentialed 路径先校验凭证的号／文章作用域；浏览器只向相同 HTTPS 文章域发送已有 Cookie，不写会话、不改页面布局。正文拒绝／身份未知时停止相关后续请求，不匿名回退；分项成功与截图完整性分别验收。
- `validation/curl_bridge.py` 仅用于当前 Agent 的有限 HTTP 验证：通过项目临时目录的 0600 FIFO 与已获准的独立 curl 命令交换配置及响应，秘密仅留内存／管道，不写普通配置或原始响应。状态和回执只含路径、编号、数量及数字状态码；无监听端口、系统代理或常驻服务。仅处理固定两号及样本调用，最多 46 次、600 秒，样本模式与普通入口共用重叠锁；不用于突破未获准的网络权限或运行任意命令。
- `validation/profile_context.py` 仅验证两个已确认目标号的正常主页会话前置条件，不扫描本机缓存或其他账号。主页 HTTP／身份／令牌门槛通过后才进行一次列表请求；服务端新会话字段只留本次内存，不轮换凭证文件、不处理验证码或受限页、不根据第三方错误映射猜测失效原因。
- `validation/profile_capture.py` 仅用于另行获准的主页／列表实验：精确匹配两号的 `/mp/profile_ext` home／getmsg 请求，仅保存白名单查询、Cookie 与必要头部到本次私有实验目录；不保存原始 URL、完整头部或流量，不读取响应正文。每号首次列表候选只作一次即时 HTTPS 功能核对，字段过滤差异与真实身份／时间分别验收；不覆盖已有文章凭证。`capture_session.py` 的 profile 模式使用独立、不可重跑的实验目录，复用原有系统收尾控制。
- 采集诊断仅记录固定计数：目标主机请求／响应及已知路径分类、TLS 失败的目标／其他／未知主机分类；目标主机错误仅在内存中映射到固定原因类别，不保存其他主机名、任意路径、查询值、证书或错误原文。它们用于区分观测阶段，不能单独认定账号身份、缓存、证书固定或访问限制，也不能追补旧实验缺失的观测。
- `validation/transport_diagnostic.py` 负责须每次单独授权的 120 秒、无凭证诊断：一个固定公开控制请求通过本次代理并校验证书，记录控制与普通流量的独立计数。只有控制请求与代理侧观测都成立才提示正常刷新猫笔刀主页；不采集 Cookie／令牌、不读取旧凭证、不发列表探针。diagnostic 固定目录和恢复入口独立，不复用已结束实验的授权；此模块不负责系统设置，仍复用单次控制器。
- 刷新前后取样沿用 `validation/transport_diagnostic.py`，只返回受控阶段名、UTC 时间、剩余窗口及白名单计数；必须在控制通过且实验仍运行时取样，取样不等于 UI 刷新成功。Computer Use 只操作已确认的目标公众号主页，界面工具不可用时不启动依赖点击的新系统实验，不读取聊天、缓存或账号数据作为替代。
- Agent 操作的单次短诊断沿用现有控制器，固定独立目录 `.auth/wechat-capture/ui-diagnostic-session/` 及专用恢复入口；前面三次实验必须均已恢复、停止，旧目录不重跑。仅在目标主页可确认、控制门槛通过后操作一次刷新，按实际 UI 状态及取样记录验收；不得把正常终端启动或照片当作 Agent 已刷新。
- 文章页对照诊断复用上述控制器、无凭证计数及取样，独立固定目录 `.auth/wechat-capture/article-diagnostic-session/`；前四次均已恢复、停止后才允许启动。仅操作猫笔刀固定技术样本文章，120 秒、一次刷新，不采 Cookie／令牌、不发列表或评论探针；只在安全确认该文章窗口和控制门槛后执行，不扩大信任／代理／主机范围。专用入口和恢复路由不得复用旧目录。
- `validation/certificate_scope.py` 仅离线评估证书 NameConstraints：复用隔离环境已有 cryptography 生成构造证书，标准库 MemoryBIO 在内存中握手；macOS 验证只使用显式测试根、禁止钥匙串搜索／网络补链与在线吊销查询，以 verbose 输出读取固定数字诊断，不能把 CT 提示单独当根因。不导入系统信任、不监听或访问微信、不改实际采集证书；私钥只在本次临时目录并自动清理，档案只保留公共证书、固定结果和校验值。根约束与中间证书约束不能混淆，验证器拒绝／不可用不能当约束保护通过，离线结果不等于微信兼容或授权放宽信任。
