# 任意微信公众号文章链接立即归档

创建：2026-10-22 08:00（北京时间）。用户已在客户端设置本 Goal 为 active，目标为「帮我增加给任意链接立即归档的能力」；随后明确范围为任意微信公众号文章链接。沿用现有 Goal，不重复创建。

## 目标、边界和目录

增加 `liumo save URL`：接收任意公众号的公开短链／长链，立即读取原文，保存 Markdown、本地配图、来源及状态元数据，不依赖 RSS 收录或订阅名单。正常可访问文章应实际保存；访问受限、付费或缺失内容不能伪造成功。评论不请求，截图暂缓。

使用已有 Playwright、正文副本选择和 Markdown／图片组件，无新依赖。新增 `liumo/manual.py` 负责输入、手动任务及项目浏览器会话；`tests/test_manual*.py` 保存对应测试，`docs/manual-archive.md` 保存用法和限制。手动状态位于忽略的 `state/manual/`、归档位于 `archives/manual/`，原始 HTML／JS 和凭证不写普通日志或公开证据；浏览器专用会话为 `.auth/manual-article/`，不读取其他应用或旧实验会话。

直接使用正常项目浏览器加载文章，不先请求受限再轮换 UA／账号。浏览器遇到验证时只等待用户正常完成，不自动操作验证码、不绕过访问控制；需要登录时说明对象、会话位置和请求去向，由用户操作。正式自动追更、启用时间、基线和系统任务不改。

现有未完成历史导入代码保持原样；`liumo/__main__.py` 仅增添独立 save 分支，不修改既有 history 逻辑。无 Git 提交／推送／tag、全局依赖、系统配置、部署或 guixu 修改。
